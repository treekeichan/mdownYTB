mdownYTB v0.2.2 Windows x64 release - third-party source and replacement information

This release dynamically links Qt 6.11.0 and includes MinGW runtime DLLs. The
application source corresponding to this executable is published at:
https://github.com/treekeichan/mdownYTB/tree/v0.2.2

Qt 6.11.0 source (exact upstream release archive):
https://download.qt.io/official_releases/qt/6.11/6.11.0/single/qt-everywhere-src-6.11.0.tar.xz
Qt licensing and LGPL notices:
https://www.qt.io/development/open-source-lgpl-obligations

The Qt DLLs are unmodified shared libraries. Users may replace the Qt DLLs
with compatible modified versions and run this application against them. The
application does not prevent replacement or reverse engineering for debugging
modifications to the LGPL libraries. The corresponding application source is
available at the GitHub tag above.
